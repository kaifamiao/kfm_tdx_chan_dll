# KFM 缠论通达信指标（公式 + DLL 模式）

在通达信主图/副图完整画出缠论分析结构：**K线包含处理、分型、笔、线段、笔中枢，
以及双层买卖点信号（确认层 + 预警层）**。核心计算在 C 语言 DLL（9 号槽）中完成，
通达信公式只负责取数与绘图。

## 功能一览

| 模块 | 内容 |
|---|---|
| K线处理 | 包含关系合并（方向动态判定），被合并组画空心框 |
| 分型 | 合并K序列上的严格三K分型，「顶」「底」文字标注 |
| 笔 | 严格笔（顶底交替，合并K间隔 ≥ 4），黄色折线 + 端点数值 |
| 线段 | 特征序列分型法，品红粗折线 +「段顶」「段底」 |
| 中枢 | 笔中枢，纯 STICKLINE 四边矩形 + ZG/ZD 数值 |
| 买卖点·确认层 | 1买/2买/3买、1卖/2卖/3卖（笔级别，反向笔成立后判定） |
| 买卖点·预警层 | 预1买/预2买/预3买、预1卖/预2卖/预3卖（分型密封即判定，早约 2-4 根K线） |

**信号稳定性**：两层信号一旦出现均永不移动、永不消失（流式回归验证零漂移）。
预警层灵敏、误报稍多；确认层晚、权威。实战以预警作提示、确认层作依据。

## 快速开始

### 1. 编译（MinGW-w64，`D:\mingw64`）

```bat
build.bat
```

等价命令：

```bat
D:\mingw64\bin\gcc.exe -O2 -shared -o kfm_chan_DLL.dll kfm_chan_DLL.c kfm_chan_DLL.def -lm
```

### 2. 离线验证（不需启动通达信）

```bat
python verify_dll.py
```

通过标准：`L1+L2 验证: 559/559 通过`。覆盖：接口契约、5 类合成数据
（趋势/随机/波浪/台阶/横盘）× 3 种长度 × 全部选择器逐 bar 比对、
脏值净化（NaN/停牌/1e31）、信号流式防漂移、确认bar锚定模式。

### 3. 部署

关闭通达信全部进程（`TdxW` 会自启，需循环关闭），复制到：

```
C:\new_tdx64\T0002\dlls\kfm_chan_DLL.dll
```

并在 `dlls.ini` 绑定 `band9=kfm_chan_DLL.dll`（公式前缀即 `TDXDLL9`）。

### 4. 导入公式

- 主图：新建技术指标，名称 `KFM_CHAN`，画线方法**主图叠加**，粘贴 `KFM_CHAN.txt`
- 副图：新建技术指标，名称 `KFM_CHAN_BS`，画线方法**副图**，粘贴 `KFM_CHAN_BS.txt`

详见 [使用说明.md](使用说明.md)。

## DLL 接口设计

通达信一次调用只能传 1 个序列 + 2 个常数，故采用三次调用模式：

| 功能号 | 函数 | 作用 |
|---|---|---|
| 1 | `KFM_SetH` | 存入 HIGH 序列（回显输出） |
| 3 | `KFM_SetC` | 存入 CLOSE 序列（买卖点 MACD 背驰用） |
| 2 | `KFM_Out` | 存入 LOW 后执行全量计算，`pfINb[0]`=输出选择器，`pfINc[0]`=1 锚定确认bar / 777 写调试日志 |

选择器（0 值 = 该 bar 无输出）：

| 选择器 | 输出 | 选择器 | 输出 |
|---|---|---|---|
| 1/2 | 顶/底分型值 | 16-19 | 中枢矩形四角标记 |
| 3 | 全部笔端点（POLYLINE） | 20-25 | 确认层 B1/B2/B3/S1/S2/S3 |
| 4 | 全部线段端点 | 26-31 | 预警层 预1买-预3买/预1卖-预3卖 |
| 5/6 | 中枢上沿 ZG / 下沿 ZD | 90-95 | 诊断常量（K线/笔/线段/中枢/合并组/分型数） |
| 7/8 | 被合并K线组高/低 | 9-12 | 笔顶/笔底/线段顶/线段底 |

接口铁律（源自《通达信DLL编写注意事项.MD》实测）：
`#pragma pack(1)` 且 `sizeof(PluginTCalcFuncInfo)==10`；只导出 `RegisterTdxFunc`；
计算函数五参 `__cdecl`；函数表以 `{0,NULL}` 结尾；无 `DllMain`；拒绝二次注册。

## 买卖点口径

**确认层（笔级别）**：

- 1买 = 跌破最后中枢 ZD 且创新低 + MACD 背驰（下跌笔负柱面积减小且 DIFF 不创新低）
- 2买 = 一买后首个不破一买低点的底
- 3买 = 中枢向上离开后首次回抽笔底不破 ZG
- 卖点镜像。背驰基于 CLOSE 的 MACD(12,26,9)

**预警层（分型级别，分型右侧第 2 根合并K成型即密封判定）**：

- 预1买 = 底分型相对前底分型创新低 + 负柱面积缩小 + DIFF 抬高
- 预2买 = 预1买后不创新低的首个底分型
- 预3买 = 中枢形成后突破 ZG、回抽底分型守住 ZG
- 卖点镜像

锚定：默认标在信号端点 bar（价格位置准确）；`pfINc[0]=1` 时标在确认 bar
（信号判定成立的那根新K线，完全不补历史）。

## 已知坑（血泪经验）

- **中枢绝不能用 DRAWLINE 画边**：TDX 的 DRAWLINE 会把所有触发点连成连续折线，
  相邻中枢之间会出现粘连连线。中枢矩形用纯 STICKLINE 四边；笔/线段的 zigzag
  反而正需要 DRAWLINE 的该行为。
- DRAWTEXT 动态字符串（STRCAT/CON2STR）全局只求值一次 → 显示 0.00；
  数值标注一律用 DRAWNUMBER。
- 相邻中枢共享边界 bar：选择器 5/6 先写者保留，16/18 起点标记右移 1 格，
  保证起/终标记严格交替。
